# Brand

## Identity

**Tanmay’s Portfolio** is a dark Build Log for **Tanmay Patel, Backend & Applied AI Engineer**. Use the approved mockup for the closed cover, spine, graphite paper, and left-side bookmarks.

## Typography

| Role | Typeface |
| --- | --- |
| Cover and major spread titles | Instrument Serif |
| Body, controls, and tabs | Instrument Sans |
| Code, metrics, and identifiers | JetBrains Mono |

Use readable body text, short line lengths, and restrained uppercase labels. Provide system font fallbacks.

## Color and surfaces

| Role | Color |
| --- | --- |
| Backdrop | `#101011` |
| Cover | `#19191B` |
| Graphite paper | `#242325` |
| Primary ink | `#F2E6D5` |
| Muted ink | `#BFB4A8` |
| Copper accent | `#DE9A70` |

Use dark mode only. Reserve copper for active bookmarks, links, and focus indicators. Keep linen grain and graph rules subtle enough to read over. Use shadows to define the cover, spine, and page edges. Use labeled icons for useful actions and accessible names for icon-only controls.

## Voice

Write in plain English. Use first person for Tanmay’s contributions and short labels for actions. Explain the engineering decision in concrete terms. Use measured results only when the source supports them.
